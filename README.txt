日本心霊スポット図鑑 v7 OSM安定版
=================================
目的:
- v5で動いていた 詳細画面 / 移動方法 / 写真保存 を維持
- ホーム上部の地図だけ OpenStreetMap に変更

特徴:
- 47スポットを OpenStreetMap に赤ピン表示
- ピンをタップすると詳細画面を開く
- 現在地を青マーカー表示
- 読み込み失敗時でも検索・詳細・写真保存は使える
- ルート表示・写真保存機能は v5 と同じ

GitHub更新:
index.html / manifest.webmanifest / sw.js を上書きして Commit changes。
